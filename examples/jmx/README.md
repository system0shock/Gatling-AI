# Golden migration fixtures

Two synthetic JMeter plans that exercise the JMeter → Gatling pipeline end to end.

| File | Shape | Expected gate |
|---|---|---|
| `simple-backend.jmx` | one Ultimate TG, 3 transactions, regex + jsonPath, CSV, UDV, large body, one typical JSR223 | `passed` (after pass-2 translation) |
| `staged-pipeline.jmx` | two staged TGs, inter-thread `props`, complex JSR223, kafka-via-proxy, JDBC sampler | `passed_with_warnings` |

Both `.jmx` are generated by `jmx_build.py` (committed; a determinism test guards drift).

## Run

Fast tier (no Maven, runs in the normal suite):

    python -m pytest examples/jmx/ -q

Gate tier (opt-in, needs Maven + JDK):

    GATLING_AI_E2E=1 python examples/jmx/run_golden_e2e.py

Converted artifacts live in `examples/scenarios/SHOP/legacy-backend-010/` and
`.../legacy-staged-011/`.
